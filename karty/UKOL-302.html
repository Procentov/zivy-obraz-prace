Proč to děláme

Mirek 20. 11. 2026 : kniha znalostí je jediný zdroj pro JAKOUKOLI práci, ne jen pro zápis do knihy; žádný AI asistent ji nesmí minout, aby Mirek nemusel říkat totéž podruhé. Pravidlo existuje , ale má dvě díry: potvrzenka dosvědčuje přečtení libovolné stránky, ne stránky tématu karty ; stejný zámek pro Claude Code není postaven . Navazující nález pro : hlídač rozhodnutí vrátil HTTP 400 dvakrát , na něj se vynucování spoléhat nesmí. Cíl je jiná věta než u karet 74/127/151/181/196: nejde o práci bez Mirka, jde o to, že zámek na knihu nelze obejít. Staví se ve Velínu, rozhodnutí JAK pracovat zůstává v projektu Způsob práce

Kam chceme dojít

Asistent nemůže pracovat na kartě, aniž přečetl stránku knihy jejího tématu: zápis a spuštění přes Vrátného odmítne potvrzenku z cizí stránky, totéž platí pro Claude Code mimo kartu 267. Měřítko napsané předem: zkouška se 3 podstrčenými chybami — čtení cizí stránky → zápis odmítnut; správná stránka → projde; Claude Code zápis bez potvrzenky → odmítnut; 3 z 3 odmítnuto/projde správně
